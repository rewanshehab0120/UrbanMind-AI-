## 📂 محتويات المجلد والـ Data Dictionary

### 1. `weather_cairo.csv` / `weather_cairo1.csv` (السجل التاريخي بالساعة)
يحتوي على السلسلة الزمنية التاريخية الممتدة (أكثر من 17,500 تسجيل ساعي) لأرصاد القاهرة الجوية.

* **`datetime`**: التاريخ والوقت بالساعة (تنسيق `YYYY-MM-DD HH:MM:SS` - Primary Key زمني).
* **`temperature_c`**: درجة الحرارة المئوية (°C).
* **`humidity_percent`**: نسبة الرطوبة الجوية (%).
* **`precipitation_mm`**: معدل هطول الأمطار الإجمالي مقاساً بالمليمتر (mm).
* **`rain_mm`**: صافي كمية الأمطار الساقطة (mm).
* **`pressure_hpa`**: الضغط الجوي مقاساً بالهكتوباسكال (hPa).
* **`wind_speed_kmh`**: سرعة الرياح مقاسة بالكيلومتر/ساعة (km/h).
* **`wind_direction`**: اتجاه الرياح بالدرجات (من 0° إلى 360°).
* **`cloud_cover_percent`**: نسبة التغطية بالسحاب (%).
* **`latitude` / `longitude`**: الإحداثيات الجغرافية لمركز محطة الرصد بالقاهرة.
* **`location`**: اسم موقع الرصد (`Cairo`).

---

### 2. `weather_hourly_profile.csv` / `weather_hourly_profile1.csv` (النمط المتوسط الساعي)
ملف مجمع يمثل متوسط التغيرات المناخية المتوقعة خلال ساعات اليوم الـ 24 المعتادة لتبسيط عمليات التنبؤ والتحليل المباشر.

* **`hour`**: رقم الساعة في اليوم (من 0 إلى 23).
* **`avg_temperature_c`**: متوسط درجة الحرارة المتوقعة لهذه الساعة.
* **`avg_humidity_percent`**: متوسط نسبة الرطوبة المتوقعة.
* **`avg_wind_speed_kmh`**: متوسط سرعة الرياح المتوقعة.
* **`rain_probability_percent`**: احتمالية هطول الأمطار المئوية لهذه الساعة.
